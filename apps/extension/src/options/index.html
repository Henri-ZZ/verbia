How it works

Open a Reddit reply box and Verbia appears directly below it. The toolbar icon opens the Verbia menu — open Settings from there. On other sites, use the keyboard shortcut for Universal Mode.

Privacy by design

Verbia sends data only when you click Generate and never clicks a website’s send or submit controls.
