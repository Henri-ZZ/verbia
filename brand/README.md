# Verbia brand mark

The mark is a layered **V** made from three rounded strokes. The repeated shape represents one intent being carried faithfully across different languages; the forward dark-green layer is the final wording delivered to the reader.

## Assets

- `verbia-mark.svg` — master square symbol for product icons and avatars.
- `verbia-logo.svg` — horizontal symbol and wordmark.
- `icons/verbia-mark-{16,32,48,128,512}.png` — raster exports for browser-extension and store use.
- `verbia-logo-preview.png` — review preview of the horizontal lockup.

## Colors

| Role | Value |
| --- | --- |
| Primary green | `#0F6E56` |
| Supporting sage | `#7FA28D` |
| Soft echo | `#C7D5C4` |
| Warm background | `#F2EDE2` |
| Wordmark | `#172019` |

## Usage

Use the symbol alone below 128 px. Do not place the word "Verbia" inside browser-extension icons. Use the horizontal lockup when there is enough width for the wordmark. Keep clear space around the mark equal to roughly one quarter of its width, and do not recolor individual layers independently.

The horizontal lockup (`verbia-logo.svg`) is used at the top of the settings page and the reply panel, where the bare wordmark previously stood. It ships with the extension at `icons/verbia-logo.svg` (declared in `web_accessible_resources` for the content-script panel).
